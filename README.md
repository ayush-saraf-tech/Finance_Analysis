# Finance Analytics Dashboard – Power BI

## Project Overview
Developed an interactive Finance Analytics Dashboard for ICICI Bank using Microsoft Power BI to analyze financial transactions, customer behavior, and business performance. The dashboard features two dedicated views: an Overview Analysis page for monitoring financial KPIs and trends, and a Transactions page for detailed, record-level analysis.

## Key Features

- **Financial KPIs:** Tracks total transaction amount, transaction count, average transaction value, total fees, and total tax, with Year-over-Year (YoY) comparisons.
- **Monthly Trend Analysis:** Visualizes monthly transaction amounts to identify trends and fluctuations.
- **Transaction Status Analysis:** Compares successful, failed, and pending transactions.
- **Customer Segmentation:** Analyzes financial contributions across Retail, Premium, SME, Corporate, and Wealth segments.
- **Geographical Analysis:** Evaluates state-wise transaction amounts to identify high-performing regions.
- **Transaction Type Analysis:** Compares transaction amounts, fees, taxes, and transaction counts across different transaction categories.
- **Customer Demographics:** Examines transaction value distribution by gender.
- **Detailed Transaction Records:** Provides a tabular view of individual transactions, including transaction ID, date, customer name, transaction type, status, gender, customer segment, state, amount, fees, and tax.
- **Interactive Filtering:** Enables dynamic analysis through Year, Dynamic Metric, Occupation, and Category filters.

## Tools & Technologies
- Microsoft Power BI
- Power Query for Data Transformation
- DAX for Measures and KPI Calculations
- Data Visualization and Dashboard Design

## Outcome
Created a two-page interactive financial analytics solution combining high-level business insights with detailed transaction-level reporting. The dashboard enables effective performance monitoring, customer analysis, and data-driven financial decision-making.
