# Finance Analytics Dashboard – Power BI

## Project Overview
Developed an interactive Finance Analytics Dashboard using Microsoft Power BI to analyze financial transactions, customer segments, transaction performance, fees, and taxes. The dashboard provides a consolidated view of financial KPIs and year-over-year (YoY) performance to support data-driven business decisions.

## Key Features
- **Financial KPIs:** Monitors total transaction amount, transaction count, average transaction value, total fees, and total tax, including YoY comparisons.
- **Monthly Trend Analysis:** Visualizes monthly transaction amounts to identify trends, fluctuations, and potential seasonal patterns.
- **Transaction Status Analysis:** Compares successful, failed, and pending transactions to evaluate transaction performance.
- **Customer Segmentation:** Analyzes financial contributions from Retail, Premium, SME, Corporate, and Wealth customer segments.
- **Geographical Analysis:** Evaluates state-wise transaction amounts to identify high-performing regions.
- **Transaction Type Analysis:** Compares transaction amounts, fees, taxes, and transaction counts across different transaction categories.
- **Customer Demographics:** Examines transaction value distribution by gender.
- **Interactive Filtering:** Enables dynamic analysis using year, selected measures, occupation, and category filters.

## Tools & Technologies
- Microsoft Power BI
- Data Cleaning and Transformation
- DAX Measures and KPI Calculations
- Data Visualization and Dashboard Design

## Outcome
Created a centralized financial reporting dashboard that simplifies KPI monitoring, highlights transaction trends, and enables comparative analysis across customer segments, regions, and transaction types to support financial performance evaluation and business planning.
